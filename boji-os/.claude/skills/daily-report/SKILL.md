# 每日日报

1. 先看当天日志有没有缺：身体数据、三餐、训练、状态。缺的问一句（"晚饭还没记，吃了什么？"），用户说没有就跳过。
2. 运行 `node bin/boji.js report [--date D]`。脚本会把数字和提醒写进日志的「日报」一节。
3. 在 `<!-- boji:report:end -->` **后面**写「教练点评」（已有就更新），三行就够：
   - ✅ 今天做得最好的一件事
   - ⚠️ 最大的一个风险（从脚本的提醒里挑最重要的，没有就写"无"）
   - 👉 明天只做一件事（具体、可执行，比如"早餐加两个鸡蛋""23:30 前上床""深蹲 52.5 kg × 8"）
4. 回复用户时只发：一行核心数字 + 这三行点评。

## 判断优先级

疼痛/红线症状 > 睡眠不足 > 热量缺口过大或低于基础代谢 > 蛋白质不够 > 训练没完成 > 其他。
一天只抓一件事，别一次给五条建议。
