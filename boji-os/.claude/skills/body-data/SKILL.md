# 录入身体数据

1. 确认日期：睡眠数据算在**醒来那天**；体重是**早上空腹、排尿后**的那次。
2. `node bin/boji.js today --date <日期>` 拿日志路径。
3. 从截图读数，填进「身体数据」表对应行：
   - 晨重(kg)、睡眠(h)（写 `7h20m` 或 `7.3` 都行）、睡眠评分、准备度、静息心率、HRV、总消耗(kcal)、步数
   - **总消耗**要的是全天总消耗（Oura 的 Total burn / 手表的"活动 + 静息"），不是"活动消耗"。只有活动消耗时，写到备注里，不填这一格。
   - 看不清的格子留空，不要猜。
4. 体脂秤的体脂只在同一台秤、同样条件下有可比性，写到 `me/progress.md`，不要每天改 `profile.md`。
5. 运行 `node bin/boji.js report`，用一两句话说结论。

## 怎么解读（给用户说人话）

- 睡眠 < 7 h、准备度 < 70、HRV 明显低于自己最近两周的平均、静息心率比平时高 5 以上：今天训练降一档（RPE ≤ 7 或改成走路），不要硬上。
- 单日体重波动 1–2 kg 是水分和肠道内容物，只看 7 天平均。
- 静息心率持续升高、HRV 持续走低一周以上，同时觉得累：可能是缺口太大或恢复不够，建议减载并在周报里调整。
