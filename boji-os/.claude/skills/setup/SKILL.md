# 建档 / 改计划

## 1. 初始化

在 `boji-os/` 下运行 `node bin/boji.js init`（已存在的文件会跳过，不会覆盖）。

## 2. 先做安全筛查（不能跳过）

逐条问，任何一条回答"是"，先建议找医生评估后再开始力量训练，并把情况写进档案的「伤病和身体限制」：

1. 医生说过你心脏有问题、或只能在医生指导下运动吗？
2. 运动或休息时有过胸痛、胸闷吗？
3. 有过头晕到站不稳、或者晕倒吗？
4. 有没控制好的高血压、糖尿病，或在吃影响心率/血压的药吗？
5. 有骨头、关节、腰椎的伤病或手术史，活动会加重吗？
6. 怀孕或产后一年内吗？

## 3. 收集档案数据

一次问完，用户不知道的可以留空：

- 性别、年龄、身高、**早上空腹体重**、体脂（InBody/DEXA/体脂秤，注明来源）
- 目标：减脂 / 增肌减脂 / 维持；想在多久内达到什么样子
- 每周能练几次、每次多久；健身房还是在家（列出器械）；有没有教练
- 饮食习惯：几顿、在哪吃、忌口、过敏
- 设备：Oura / 手表 / 体脂秤

## 4. 写入

- `me/profile.md`：front matter 填数字（`activity` 按每周训练次数选，`goal` 选 cut/recomp/maintain），正文填其余信息。
- 运行 `node bin/boji.js targets`，把结果用一句话讲给用户听。

## 5. 定制训练计划

基于 `me/plan.md`（模板）按档案修改：

- **有伤病**：把相关动作换成表里的"替代动作"或更安全的变式（膝伤 → 箱式深蹲/腿举限幅；腰伤 → 先不做硬拉，用臀桥、背伸；肩伤 → 卧推换哑铃中立握、推举先停）。拿不准的写"待康复师确认"。
- **没器械**：全部换成徒手/哑铃/弹力带版本。
- **每周只能练 2 次**：A/B 各一次，每次多加一个动作。
- **零基础**：前 2–4 周只学动作，所有重量从空杆或很轻的哑铃开始。
- 每个改动在文末「调整记录」写一行：日期、改了什么、为什么。

## 6. 收尾

告诉用户接下来每天要做的三件事：起床称重 → 每餐拍照发来 → 训练后发记录/视频。
