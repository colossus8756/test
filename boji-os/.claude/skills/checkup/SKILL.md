# 体检 / 化验整理

访谈里的思路是"把医院当监测机构"：没症状时定期查，用数据早发现问题。你的角色是**整理员和翻译**，不是医生。

## 步骤

1. `node bin/boji.js checkup --date <报告日期>` 新建记录；原始照片/PDF 复制到 `me/checkups/files/`。
2. 逐项抄进「结果」表：项目、结果、单位、**报告上印的参考范围**（不同医院不一样，以报告为准）、上次结果（从 `me/checkups/` 里找）、标记（↑/↓/空）。看不清的写"看不清"，不要猜数字。
3. 「超出范围的项目」：每项用一两句话解释这个指标一般反映什么，以及和上次比的变化方向。**不要**推断"你得了某病"。
4. 「要问医生的问题」：列出具体问题，例如"LDL 3.8 比去年高 0.5，需要干预吗？""尿酸偏高，蛋白粉要不要换？"
5. 「和训练/饮食相关的提醒」：只写需要医生确认后再执行的事，例如血压偏高 → 先避免憋气的大重量、找医生确认运动强度。

## 需要尽快就医的情况

报告上标危急值、或者明显严重异常（例如血红蛋白、血钾、血糖、肝酶、肌酐、肌酸激酶显著异常），或伴随胸痛、呼吸困难、尿色呈茶色/可乐色 → 直接告诉用户**尽快联系医生/就医**，并暂停训练，不要等下次复查。

## 建议的监测频率（和医生确认）

- 每年：血常规、血脂、空腹血糖/糖化血红蛋白、肝肾功能、尿酸、血压
- 体成分：同一台机器每 8–12 周一次，有条件做 DEXA
- 家庭血压：血压偏高的人每周测几次，记到当天日志的备注
