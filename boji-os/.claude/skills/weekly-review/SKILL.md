# 每周复盘

1. 运行 `node bin/boji.js week [--date 周日日期]`，生成 `me/weekly/YYYY-Www.md`。
2. 补充脚本算不了的：
   - **力量趋势**：`grep` 本周和上周的主要动作（深蹲、卧推、硬拉、推举、引体），每个动作是进步、持平还是退步。
   - **减载判断**：距离上次减载 ≥6 周，或者两个以上主要动作连续退步、同时睡眠差/很累 → 下周减载（重量 ×0.6、组数减半）。
   - **疼痛**：同一部位一周出现 2 次以上 → 相关动作换替代动作，持续 >2 周建议看医生/康复师。
3. 在周报的「教练点评」写：
   - 本周一句话总结
   - 下周的调整（最多 3 条）：热量（±100–150 kcal）、步数、具体动作的目标重量 × 次数
   - 如果改了热量目标或体重变化超过 2 kg：更新 `me/profile.md` 的 `weight_kg`（用 7 天平均）或 `deficit_kcal`，再跑 `node bin/boji.js targets`
   - 如果改了训练计划：改 `me/plan.md` 并在「调整记录」写一行
4. 每 4 周提醒一次：量腰围、拍体型照片，记到 `me/progress.md`。

## 调整原则

- 一次只改一个变量（热量 **或** 步数，不同时改），改完至少观察 2 周。
- 数据不全（饮食记录 <5 天、晨重 <3 次）时不改热量，先把记录补齐。
- 减脂期力量能维持就算成功。连续掉力、睡不好、情绪差、女性月经紊乱 → 缺口减小或安排 1–2 周维持热量的休息期。
