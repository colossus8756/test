# 记训练 / 看动作 / 定下次重量

## 记录

1. `node bin/boji.js today` 拿日志路径。
2. 在「训练」表每个动作一行：`| 杠铃深蹲 | 3 | 8/8/7 | 50 | 8 | 第三组膝盖内扣 |`
   - 次数每组一样写一个数，不一样用 `/` 分开。
   - 自重动作重量写 0，负重引体写附加重量。
   - RPE 用户没说就问"最后一组还能再做几个？"：还能做 3 个 = RPE 7，2 个 = 8，1 个 = 9，0 个 = 10。
3. 用户问训练消耗时，按 MET 粗算并标明是估算；不要把训练消耗另外加进饮食预算（戒指的总消耗已经包含了）。

## 看视频 / 照片

视频先抽帧：`ffmpeg -i in.mp4 -vf fps=2 me/photos/<日期>/frames/%03d.jpg`（没有 ffmpeg 就让用户发 3–5 张关键位置的截图：起始、最低点、发力中段）。

对照检查，**只说看得到的东西**，看不清就说看不清：

| 动作 | 重点看 | 常见风险 |
|---|---|---|
| 深蹲 | 膝盖和脚尖同向、背部角度稳定、脚跟不离地 | 膝内扣、底部骨盆后倾（"眨眼"）、重心前移 |
| 硬拉 / 罗马尼亚硬拉 | 腰背中立、杠贴腿 | 弓腰、杠离身体、锁定时过度后仰 |
| 卧推 | 肩胛后收下沉、肘角约 45°、臀不离凳 | 肘外展 90°、杠落点太高、弹胸 |
| 推举 | 臀腹收紧、杠走直线 | 腰过度后仰 |
| 引体 / 下拉 | 先沉肩再拉、全程控制 | 耸肩、甩身体 |

发现风险时：说清楚哪一帧、什么问题、下次怎么改（减重 5–10%、放慢下放、换变式），建议请教练当面看。

## 下次重量（双重递增，规则在 `me/plan.md`）

1. `grep -l "<动作名>" me/days/*.md` 找到最近两三次同一动作。
2. 所有组都做到次数区间上限、RPE ≤ 8 → 下次加重（上肢 +1–2.5 kg，下肢 +2.5–5 kg）。
3. 没做满 → 同重量再来，目标多做 1 次。
4. 连续两次退步 → 先看睡眠、热量缺口是不是太大，再考虑减载周。

## 疼痛

用户提到任何疼痛，先写进「状态 → 疼痛/不适」，再按 `docs/safety.md` 处理：

- 锐痛、关节卡住、麻木放射、胸痛、头晕 → **立刻停**，建议就医。
- 训练中 ≤3/10 的钝痛、第二天早上没加重 → 可以继续，但这个动作减重或缩小幅度。
- >3/10 或第二天更疼 → 这个动作暂停，换不疼的替代动作；超过 1–2 周不好转去看医生/康复师。
