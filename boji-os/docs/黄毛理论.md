## 3. 邵艾伦原版：两性关系里的黄毛思维

### 3.1 最早的六条（2026-08-15，《我对王水牛事件的看法》）🟢
1. **保持选项开放**（keep options open），不随便确认关系
2. **不过度讨好、不跪舔**——"黄毛思维的对立面就是跪舔思维"
3. "一个顶级的黄毛，**从不会用钱买感情**"
4. "精神小妹要走，**慢走不送**"
5. **永远在提升自己**，"always going somewhere"
6. **随时接受对方退出**，"设置退出机制"；他把轻易给出法律承诺（结婚）称为"儿童行为"

### 3.2 完整版（2026-09-15，《你需要黄毛思维》）🟢
- **SMV 两层**：客观 SMV（身高、钱、长相）"只是入场券"；体感 SMV 是对方主观感受到的你。"薄肌，提升客观 SMV；黄毛思维，提升体感 SMV……薄肌 + 黄毛 = 版本答案"。
- **黄毛的特质**："不怕冒犯、敢调侃、敢表达不同的意见、敢对抗"，让人感到你"有选择权""不缺爱"。
- **装不出来**："黄毛思维……没有办法长期装出来"，要"真的得有事业""真的得有自己的世界"。
- **视频简介**："不是让你真的去染黄毛，也不是教你学套路。而是建立自己的生活、边界、节奏、选择权和 Purpose。"
- **金句**："She's never yours, it's just your turn."

### 3.3 健康版：留下什么，丢掉什么
| 留下 ✅ | 丢掉 ❌ |
|---|---|
| 有自己的生活、事业和目标 | 用"SMV"给人打分，把关系当市场交易 |
| 有边界，不靠讨好换认可 | 把对方的情绪当"测试"来博弈 |
| 不用钱买感情 | 把"不承诺"当成策略 |
| 尊重对方随时可以离开（就是尊重对方的自主权） | "慢走不送"式的冷漠 |
| 永远在提升自己 | 为了"显得有选择权"去刻意冷淡、操纵 |

> 邵艾伦的原版大量借用英语圈 red pill / PUA 的词汇（SMV、hypergamy、preselection、"测试"），⚪ 这也是它受批评最多的地方（见第 7 节）。

## 5. 核心机制：把黄毛变成可用的工具

### 5.1 两层过滤
| 层 | 屏蔽 | 保留 |
|---|---|---|
| 情绪层 | 嘲笑、嫉妒、"你变了"、为合群而来的压力、动机论（"你练肌肉就是想泡妞"） | — |
| 信息层 | 没有事实依据、无法验证的评价 | 有事实、可验证的批评 → 查数据、问 AI、问专业人士 → 改 |

### 5.2 噪音还是信号：收到批评时问四个问题
1. **有没有具体事实？**"你这样没用"是噪音；"你连续三周体重没变"是信号。
2. **能不能验证？**能用数据、体检、教练、多个 AI 交叉核实的，认真对待。
3. **对方的立场是什么？**他在评价你，还是在为自己的选择辩护（屁股决定脑袋）？
4. **错了代价多大？**能低成本回头的就先做，用结果说话。

### 5.3 社区的成本模型（⚪ 二次创作，可帮助理解）
来自 [chinggg/sunxue-boji-huangmao](https://github.com/chinggg/sunxue-boji-huangmao)：
- `行动成本 = 任务成本 + 面子成本 + 许可成本`。大部分人不是败在任务本身，而是败在"面子上过不去"和"等别人同意"。**黄毛把后两项压到 0。**
- 这个仓库自己也写了一条硬边界：**黄毛清零的是无关者的评价，不是你在乎的人的感受。**这条非常重要。

### 5.4 场景表
| 你会听到 | 黄毛的处理 |
|---|---|
| "练那么多干嘛，又不当运动员" | 噪音。你练的是 80 岁还能自己走路 |
| "吃蛋白粉就是打药" | 噪音，有科学答案（见 [薄肌.md](薄肌.md)） |
| "你最近好像瘦得有点狠" | **可能是信号**：查 7 天平均体重和掉重速度 |
| 教练说"你深蹲膝盖内扣" | **信号**，必须改 |
| 医生说"血压高，先别憋气上大重量" | **信号**，必须听 |
| 身体疼痛、头晕、胸闷 | **最强的信号**，立刻停（见 [safety.md](safety.md)） |
| 同事笑你辞职做副业 | 噪音；但"你的存款够撑几个月"是信号 |
| 伴侣说"你最近都不陪我" | **不是噪音**——这是你在乎的人的感受 |

**黄毛屏蔽的是别人的情绪，不是身体的信号，也不是亲近之人的感受。**

### 5.5 日常做法
- **少解释，多记录**：不用向每个人证明你在做什么，日志就是底气。三个月后的数据比现在的争论有说服力。
- **小范围公开**：只对能给有效反馈的人（教练、伙伴、AI）公开进度。
- **每月自检一次**：我最近屏蔽掉的批评里，有没有其实是对的？

## 7. 批评与争议

- **自我免疫的话术设计**：⚪"黄毛理论预设了'你会遭到质疑'……把任何反驳都收编为'你还没升级'的证据"（[bushenghan22](https://github.com/bushenghan22/bushenghan-sun-yuchen-interview)）。这是最值得警惕的一点：一个理论如果能把所有反对都解释成"证明我对"，它就无法被证伪。第 5 节的"四个问题"就是为了对冲这个风险。
- **性别与物化**：⚪ 邵艾伦原版借用 red pill / PUA 词汇，把关系描述成 SMV 市场和"测试"博弈；孙宇晨在访谈里把批评者称为"小仙女们"[02:22:05](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=8525s)。⚪ 知乎有文章称它和"大结果理论"一样，把人的品质简单化成标签。
- **幸存者偏差**：⚪"异类才能拿到大结果"——拿到大结果的人里异类确实多，但大多数异类并没有大结果。无视外界评价往往需要有兜底资源。
- **营销引流**：⚪ 邵艾伦在访谈里两次提到自己的黄毛思维视频；有评论认为双方都在借对方的流量。
- **回音室**：只对支持者公开、屏蔽反对者，久了只能听到自己想听的。
