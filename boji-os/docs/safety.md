# 保护身体：安全守则

> 这份守则优先于训练计划、热量目标，也优先于访谈里的任何说法。
> 这里是通用的运动安全常识，**不是医疗建议**；有病史或拿不准时，以医生和康复师的意见为准。

## 1. 开始之前先找医生的情况

下面任何一条为"是"，先做医学评估再开始力量训练：

- 有心脏病史，或医生说过只能在指导下运动
- 运动或静息时出现过胸痛、胸闷
- 头晕到站不稳、晕倒过
- 高血压、糖尿病没控制好，或在吃影响心率/血压的药
- 骨关节或腰椎有伤病、手术史，活动会加重
- 怀孕或产后一年内

## 2. 红线：出现就立刻停止训练

| 症状 | 怎么做 |
|---|---|
| 胸痛、胸闷、压迫感，可能放射到手臂/下巴 | 立刻停止，休息不缓解马上就医（急救电话） |
| 与运动量不相称的呼吸困难 | 停止，就医 |
| 头晕、眼前发黑、要晕倒 | 停止，坐下或躺下，持续或反复要就医 |
| 关节锐痛、卡住、错位感、听到"啪"一声后疼 | 停止该动作，冰敷制动，看医生 |
| 手脚麻木、刺痛、疼痛沿胳膊/腿放射 | 停止，看医生（可能和神经受压有关） |
| 训练后 1–3 天肌肉剧痛肿胀 + 尿液呈茶色/可乐色 | **马上就医**（横纹肌溶解的信号） |
| 突发剧烈头痛（尤其憋气发力时） | 停止，就医 |

## 3. 疼痛分级规则（0–10 分）

| 训练中疼痛 | 第二天早上 | 怎么做 |
|---|---|---|
| ≤ 3/10 钝痛 | 没加重 | 可以继续，但这个动作减重或缩小幅度 |
| > 3/10 | 或第二天更疼 | 这个动作暂停，换不疼的替代动作 |
| 任何程度 | 超过 1–2 周不好转 | 去看医生/康复师 |

肌肉酸痛（练后 24–72 小时、对称、按压肌肉疼、活动后减轻）是正常的，和关节疼不是一回事。

## 4. 训练安全

- **热身不能省**：5 分钟有氧 → 动态活动 → 递增热身组（空杆 ×10 → 50% ×5 → 70% ×3 → 85% ×1）。
- **前 2–4 周只学动作**：轻重量、有教练看，或拍视频给 Claude 和教练检查。
- **留余力**：正式组 RPE 7–8（还能再做 2–3 次）。新手阶段大重量复合动作不做到力竭。
- **加重要慢**：每次上肢 +1–2.5 kg、下肢 +2.5–5 kg，做满次数区间上限才加。
- **不憋气硬顶**：血压偏高的人避免长时间憋气（瓦氏呼吸），先和医生确认。
- **深蹲、卧推用保护**：深蹲架设好保护杆；卧推大重量要有人保护，或用史密斯机/哑铃。
- **恢复**：同一肌群间隔 48 小时；每 6–8 周减载一周；睡眠 7–9 小时。

## 5. 减脂安全

- 每日热量缺口建议 300–500 kcal，**不超过 600**。
- 每日摄入**不低于基础代谢**；每周掉体重 0.5%–1%，更快通常意味着掉了肌肉。
- 蛋白质每公斤体重 1.6–2.2 g，脂肪不低于 0.6 g/kg。
- 出现这些信号要减小缺口或休息 1–2 周维持热量：力量连续下降、睡不好、一直很冷很累、情绪低落、头发明显变多脱落、女性月经紊乱或停经。
- 有进食障碍史，或者对吃东西有强烈的内疚、失控、催吐等情况：不要自己算热量减脂，先找专业人士。
- 补剂：蛋白粉和肌酸（每天 3–5 g）是研究最充分、风险最低的两种；肾脏有问题的人先问医生。不要碰合成代谢类固醇、SARMs、来路不明的"燃脂"产品。司美格鲁肽、替尔泊肽这类药必须在医生指导下用，用的时候更要保证蛋白质和力量训练，减少肌肉流失。

## 6. 定期监测（"把医院当监测机构"）

- 每年：血常规、血脂、空腹血糖/糖化血红蛋白、肝肾功能、尿酸、血压
- 体成分：同一台机器每 8–12 周，有条件做 DEXA
- 用 `checkup` 技能把报告整理进 `me/checkups/`，和往年对比

## 7. AI 的局限

- 照片估热量误差常在 ±20–30%；手环/戒指的消耗估算也有 ±10–20% 误差。看趋势，不纠结单日数字。
- Claude 看视频只能看到画面里的东西，不能代替教练当面纠正，也不能代替医生诊断。
- 任何"AI 说可以"的建议，如果和这份守则冲突，以守则为准。
